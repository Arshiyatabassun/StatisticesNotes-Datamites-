11. What is Mean?

Mean is the average value of a dataset.

Formula:

Mean = Sum of all values / Number of values

Example:

10, 20, 30
Mean = (10 + 20 + 30) / 3 = 20
How do you calculate Mean?

Add all observations and divide by the number of observations.

Example:

5, 10, 15, 20

Mean = 50 / 4 = 12.5

What is Median?

Median is the middle value when data is arranged in ascending or descending order.

Example:

10, 20, 30

Median = 20

If there are an even number of observations:

10, 20, 30, 40

Median = (20 + 30) / 2 = 25
